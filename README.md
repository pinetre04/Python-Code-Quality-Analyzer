
# Python Code Quality Analyzer

### AST 기반 Python 소스코드 정적 분석 및 품질 평가 시스템

Python의 추상 구문 트리(Abstract Syntax Tree, AST)를 활용하여
소스코드의 구조와 복잡도를 분석하고, 코드 품질 개선 사항을
자동으로 탐지하는 웹 기반 정적 분석 도구입니다.

## 1. 프로젝트 개요

본 프로젝트는 소프트웨어 개발 과정에서 코드의 구조적 품질을
객관적인 지표로 확인하고, 유지보수성을 개선하기 위해 개발되었습니다.

Python 내장 ast 모듈을 이용하여 소스코드를 실행하지 않고
함수 및 클래스 구조를 분석하며, Streamlit을 통해 분석 결과를
시각적으로 제공합니다.

## 2. 주요 기능

### 소스코드 구조 분석
- 전체 코드 라인 수 측정
- 함수 및 클래스 개수 분석
- 함수별 시작 위치 및 길이 분석

### 코드 복잡도 분석
- 조건문 및 반복문을 기반으로 함수 복잡도 측정
- 복잡도 기준을 초과하는 함수 탐지
- 함수별 복잡도 비교

### 코드 품질 검사
- 50줄을 초과하는 함수 탐지
- 복잡도 10을 초과하는 함수 탐지
- Docstring이 없는 함수 탐지

### 분석 결과 시각화
- Streamlit 기반 웹 대시보드
- 함수별 분석 결과 테이블
- 코드 품질 개선 사항 출력
- 원본 소스코드 미리보기

### 리포트 생성
- 분석 결과를 CSV 파일로 다운로드
- 발견된 문제의 위치 및 유형 기록

## 3. 기술 스택

| 구분 | 기술 |
|------|------|
| Programming Language | Python |
| Static Analysis | Python AST |
| Web Framework | Streamlit |
| Data Processing | Pandas |
| Version Control | Git / GitHub |

## 4. 시스템 동작 과정

1. 사용자가 Python 소스코드(.py) 업로드
2. AST 기반 소스코드 파싱
3. 함수 및 클래스 구조 추출
4. 함수별 코드 길이 및 복잡도 분석
5. 코드 품질 검사 규칙 적용
6. 분석 결과를 웹 대시보드에 출력
7. CSV 형식의 품질 분석 리포트 제공

## 5. 실행 방법

### 1) Python 가상환경 생성

Windows CMD 기준:

```cmd
py -m venv .venv
```

### 2) 가상환경 활성화

```cmd
.venv\Scripts\activate.bat
```

### 3) 필수 라이브러리 설치

```cmd
python -m pip install -r requirements.txt
```

### 4) 프로그램 실행

```cmd
python -m streamlit run app.py
```

### 5) 웹브라우저 접속

http://localhost:8501

Python 파일을 업로드하면 분석 결과가 자동으로 표시됩니다.

## 7. 분석 방법 및 한계

- AST를 활용하여 소스코드를 실행하지 않고 분석합니다.
- 함수 길이, 분기문 등을 활용한 규칙 기반 검사를 수행합니다.
- 복잡도는 자체 구현한 간이 측정 방식으로 계산하며,
  표준 순환 복잡도 측정 도구와 결과가 다를 수 있습니다.
- 실제 코드의 실행 성능이나 보안 취약점은 검사하지 않습니다.

## 8. 기대 효과

- Python 소스코드의 구조적 특성 파악
- 복잡한 함수 및 개선이 필요한 코드 탐지
- 코드 품질 점검 과정의 자동화
- 정적 분석과 AST 자료구조에 대한 이해 향상

## 9. 향후 개선 방향

- 코드 복잡도 측정 알고리즘 고도화
- PEP 8 기반 코딩 스타일 검사
- 다중 파일 및 프로젝트 단위 분석
- 분석 결과의 PDF 리포트 생성
- 코드 품질 변화 추적 기능
